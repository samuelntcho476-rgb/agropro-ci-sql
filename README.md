# AgroPro_CI – SQL Data Analysis

## 📌 Description

**AgroPro_CI** est un projet personnel réalisé dans le cadre de mon
apprentissage autodidacte de SQL.

L'objectif du projet est de concevoir et exploiter une base de données
permettant de centraliser et d'analyser différentes activités d'une
entreprise agro-industrielle.

Le projet couvre plusieurs domaines de gestion afin de permettre
l'exploration des données et la réalisation d'analyses à l'aide de
requêtes SQL.

---

## 🎯 Objectifs

Les principaux objectifs du projet sont :

- Analyser les données de production
- Suivre la qualité des produits et les rebuts
- Analyser les opérations de maintenance
- Étudier les activités logistiques
- Analyser les données liées aux ressources humaines
- Mettre en pratique les fondamentaux du langage SQL
- Manipuler et exploiter une base de données relationnelle

---

## 🗄️ Base de données

La base de données **AgroPro_CI** est organisée autour de plusieurs
domaines fonctionnels représentant différentes activités de
l'entreprise agro-industrielle.

Les données permettent notamment d'explorer les domaines suivants :

| Domaine | Objectif |
|---|---|
| 🏭 Production | Analyse des activités et données de production |
| ✅ Qualité | Suivi de la qualité et des contrôles |
| ♻️ Rebuts | Analyse des quantités et motifs de rebut |
| 🔧 Maintenance | Analyse des opérations de maintenance |
| 🚚 Logistique | Analyse des activités et opérations logistiques |
| 👥 Ressources humaines | Analyse des données liées aux employés |

---

## 📊 Analyses SQL

Les requêtes SQL du projet permettent d'explorer les différents
domaines de la base de données et d'en extraire des informations
utiles à l'analyse.

Les analyses portent notamment sur :

- la production ;
- la qualité ;
- les rebuts ;
- la maintenance ;
- la logistique ;
- les ressources humaines.

Le projet met en pratique différentes opérations SQL pour interroger,
filtrer, regrouper et analyser les données.

## 🎓 Contexte d'apprentissage

Ce projet a été développé dans le cadre de mon apprentissage
autodidacte de SQL.

Il constitue une mise en pratique de mes connaissances en gestion de
bases de données et en analyse de données à travers un cas
d'entreprise agro-industrielle.

L'objectif était de passer de la théorie à la pratique en travaillant
sur une base de données structurée autour de plusieurs domaines
métiers.

---

## 🚀 Perspectives d'évolution

Le projet peut évoluer vers une solution d'analyse plus complète,
notamment avec :

l'ajout de requêtes analytiques plus avancées ;
la création d'indicateurs de performance (KPI) ;
la visualisation des résultats dans un outil de Business
Intelligence ;
l'automatisation de certaines analyses.
