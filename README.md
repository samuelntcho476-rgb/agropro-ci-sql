# AgroPro_CI – SQL Data Analysis

## 📌 Description

AgroPro_CI est un projet personnel réalisé dans le cadre de mon
apprentissage autodidacte de SQL.

L'objectif est de concevoir et exploiter une base de données
permettant d'analyser différentes activités d'une entreprise
agro-industrielle.

## 🎯 Objectifs

- Analyser les données de production
- Suivre la qualité et les rebuts
- Analyser les opérations de maintenance
- Étudier les activités logistiques
- Analyser les données liées aux ressources humaines

## 🗄️ Base de données

Le projet utilise plusieurs tables représentant différents domaines
de l'entreprise.

## 🛠️ Technologies

- SQL
- [SGBD : MySQL / PostgreSQL / SQL Server...]

## 📊 Analyses

Les requêtes SQL permettent notamment d'explorer :

- la production
- la qualité
- les rebuts
- la maintenance
- la logistique
- les ressources humaines
